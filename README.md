Midnight Gallery is a top-down stealth heist in a night museum: steal every artifact, slip past patrolling guards whose vision cones are blocked by walls, hide in bushes and shadow zones, and reach the glowing exit unseen. Three wings with rising patrols, a suspicion meter with a real chance to break line of sight and cool an alarm down, and synthesised WebAudio footsteps, alarms and pickup chimes — all in vanilla JS with procedural art, playable offline in a desktop browser.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
